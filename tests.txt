ТЕСТЫ ДЛЯ ПРИЛОЖЕНИЯ mathtool
Лабораторная работа №2

Как проверять:
  Запускаю команду, смотрю вывод и код возврата.
  Код возврата в PowerShell: $LASTEXITCODE
  Код возврата в cmd: %ERRORLEVEL%
  
  Коды:
    0 - всё ок
    1 - ошибка в данных (моя проверка)
    2 - ошибка argparse (неверные параметры)


========== ОБЩИЕ ТЕСТЫ ==========

--- Запуск без параметров ---
python mathtool.py
Ожидаю: справку, код 0
[Проверено]

--- Справка ---
python mathtool.py --help
Ожидаю: справку, код 0
[Проверено]

--- Справка по команде ---
python mathtool.py solve --help
Ожидаю: справку по команде, код 0
[Проверено]

python mathtool.py stats --help
python mathtool.py series --help
python mathtool.py integrate --help
Ожидаю: справку, код 0
[Проверено]

--- Неизвестная команда ---
python mathtool.py badcmd
Ожидаю: ошибка argparse, код 2
[Проверено]

--- Неизвестный параметр ---

[Проверено]
