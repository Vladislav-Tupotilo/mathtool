   Ожидается: "ОШИБКА: неизвестный параметр", код возврата 1

7. python mathtool.py solve -a 1 -b -3 -c 2
   Ожидается: квадратное, D = 1, x1 = 2.000, x2 = 1.000, код 0

   НАБОР ТЕСТОВ mathtool
=====================

Как пользоваться: запускай команду из папки mathtool, сравнивай вывод
(stdout), сообщение об ошибке (stderr) и код возврата с ожидаемыми.
Код возврата: Windows cmd - echo %errorlevel%, macOS/Linux - echo $?
Коды: 0 - успех, 1 - ошибка в данных, 2 - ошибка командной строки (argparse).
Сообщения argparse (код 2) на английском, их точный текст не сверяем.
