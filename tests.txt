=== Тесты с параметрами командной строки ===

1. python mathtool.py
   Ожидается: справка, код возврата 0

2. python mathtool.py --help
   Ожидается: справка, код возврата 0

3. python mathtool.py badcommand
   Ожидается: "ОШИБКА: неизвестная команда", код возврата 1

4. python mathtool.py solve -a 1
   Ожидается: "ОШИБКА: неверный набор параметров", код возврата 1

5. python mathtool.py solve -a 1 -b 2 -c 3 -d 4
   Ожидается: "ОШИБКА: неверный набор параметров", код возврата 1

6. python mathtool.py solve -a 1 -x 2 -c 3
   Ожидается: "ОШИБКА: неизвестный параметр", код возврата 1

7. python mathtool.py solve -a 1 -b -3 -c 2
   Ожидается: квадратное, D = 1, x1 = 2.000, x2 = 1.000, код 0
